# Singapore Ferry mobile

Expo app that opens [singaporeferry.com](https://singaporeferry.com/) in a native WebView.

## Run locally

Install a working Node/npm distribution, then run:

```bash
npm install
npm start
```

Use Expo Go to scan the displayed QR code, or press `a` / `i` for an emulator.

The app retains the website's live content and booking flow. It shows an in-app loading state and maps Android's hardware back button to web navigation.
